# 地球防衛ファクトリー

宇宙人の大群を迎え撃つ、インクリメンタル × タワーディフェンスのブラウザゲームです。
`index.html` を開くだけで遊べます（ビルド不要・依存ライブラリなし）。

**遊ぶ: https://mkt918.github.io/earth-defense-factory/**

## 遊び方
- **防衛画面**: 地球の上をクリックして設置場所を選ぶか、右の部隊リストで購入（自動配置）。
  宇宙にカーソルを置くと範囲内の敵を自動攻撃、クリックで核ミサイル。
- **砲台は種類ごとの「部隊」**: 同じ種類を買うほどコストが上がり、その種類の全砲台（過去に置いた分も）が強くなります。5基ごとに進化。
- **内政画面**: 人口をワーカーとして金鉱山・研究所に配置。研究所が稼ぐ研究ptが貯まると星座スキルのSPになります。
- **星座スキルツリー**: 12星座の形をたどって解放。防衛研究（火力・連射・射程・迎撃・核・自動攻撃・各砲台の威力など）はすべてここ。
- 敵（重装艦・宇宙空母・母艦）は地球へミサイルを撃ってきます。撃ち落とさないと人口に大ダメージ。機関砲は迎撃に強い。
- 技術革新（リセット）でコアを得て、より先のWAVEを目指します。

## 砲台
機関砲（敵ミサイルを最優先で迎撃）／ミサイル（連射・追尾の範囲攻撃）／雷塔（連鎖）／レーザー（薙ぎ払い）／レールガン（最も体力のある敵を狙って貫通）

セーブデータはブラウザの localStorage に自動保存されます。
