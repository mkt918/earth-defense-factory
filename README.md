# 地球防衛ファクトリー

宇宙人の大群を迎え撃つ、インクリメンタル × タワーディフェンスのブラウザゲームです。
`index.html` を開くだけで遊べます（ビルド不要・依存ライブラリなし）。

## 遊び方
- **防衛画面**: 地球の上をクリックして砲台を建設。宇宙にカーソルを置くと範囲内の敵を自動攻撃、クリックで核ミサイル。
- **内政画面**: 人口（ワーカー）を設備に配置して資源を稼ぎ、設備を強化。
- **星座スキルツリー**: 12星座の形をたどって解放。
- 敵のミサイルは撃ち落とさないと人口に大ダメージ。
- 資金・研究・技術革新（リセット）で、より先のWAVEを目指します。

## 砲台
機関砲（進化でway増加）／ミサイル（連射・追尾）／雷塔（連鎖）／レーザー（薙ぎ払い）／レールガン（貫通）

セーブデータはブラウザの localStorage に自動保存されます。
