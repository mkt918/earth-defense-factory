# 地球防衛ファクトリー

宇宙人の大群を迎え撃つ、インクリメンタル × タワーディフェンスのブラウザゲームです。
`index.html` を開くだけで遊べます（ビルド不要・依存ライブラリなし）。

**遊ぶ: https://mkt918.github.io/earth-defense-factory/**

## 遊び方
- 右の部隊リストで砲台を購入すると、**最前線に自動配置**されます（地球の上をクリックして場所を選ぶことも、ドラッグで動かすこともできます）。
- **砲台は種類ごとの「部隊」**: 同じ種類を買うほどコストが上がり、その種類の全砲台（過去に置いた分も）が強くなります。5基ごとに進化。
- 宇宙にカーソルを置くと範囲内の敵を**自動攻撃**（金で威力・範囲・連射を強化できます）。クリックで**核ミサイル**（無料・再装填あり）。
- 1WAVE＝1日（DAY）。**365日を生き延び、DAY 366 のラスボス「星喰らい」を倒せばクリア**。
- **5日ごとにボス**（全11種）。倒すと**宝箱**を落とし、拾うとルーレットで**エピックアイテム**（全20種・永続強化）を獲得。
- 敵は物量で押し寄せ、ミサイルも次々と撃ってきます。人口はほとんど回復しません。**人口が0になると人類滅亡 → 転生**。
- 転生ptで**転生スキルツリー**（全100個）を**上から下へ**解放します。5本の道（火力・雷撃・守護・富・念動）が途中で3本、最後は1本に合流し、その先の【神】を目指します。効果は永続で、すべて掛け合わせです。
- 砲台は**1種類10基まで**配置できます。それ以上買うと「強化」になり、置かずに部隊全体の威力が上がります。
- ツリーで手に入る**装備スキル**（全39種）を「🧩 ビルド」でスロットに装備。同じ属性をそろえると**シナジー**（5段階）、決まった2つの組み合わせで**コンボ**（14種）が発動します。迷ったら「✨ おまかせ」。
- 遊び方は画面右上の「❓」でも確認できます。
- 重いときは「⚙ 画質」で軽量モードに（自動切り替えもあり）。
- 操作: Space で一時停止、1・2・3 で速度切り替え、Esc で画面を閉じる。

## 砲台
機関砲（敵ミサイルを最優先で迎撃）／ミサイル（追尾の範囲攻撃）／雷塔（連鎖）／レーザー（薙ぎ払い）／レールガン（最も体力のある敵へビームを照射し続ける）／火炎放射器（扇状の炎で燃やす）／冷凍砲（範囲を凍らせて減速）／重力砲（ブラックホールで吸い込む）
